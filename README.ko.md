# 🎨 Cover Studio (만능 커버 스튜디오)

### 올인원 멀티 플랫폼 썸네일 & 커버 워크플로우 · 9대 최고 오픈소스 커버 엔진 통합

크리에이터, 1인 개발자, 테크 블로거를 위한 오픈소스 AI Skill. 초기 설정에서 출력 모드를 확인하고, 글 입력 시 **3가지 디자인 안을 동시 제안**. 생성 전 **메인 헤드라인·서브 카피·태그 요소의 텍스트 계층을 반드시 확인**합니다. 브랜드 시스템(Brand System) 고정은 물론, **Codex 환경 직접 생성**과 **Nano Banana (Google Flow 무료 플랫폼) 프롬프트 출력**의 듀얼 패스를 지원합니다.

## ✨ 핵심 기능

- ⚙️ **초기 선호도 설정**: 다중 비율 일괄 출력(3:4, 2.35:1, 16:9 등) 또는 단일 규격 개별 커스텀을 최초에 확인.
- 🧠 **3가지 스타일 동시 추천**: 글 내용을 자동 분석하여 서로 다른 3가지 고품질 레이아웃 안을 즉시 제안.
- ✍️ **텍스트 계층 필수 확인 단계**: 메인 대형 텍스트, 서브 카피, 캡슐 태그 문구를 생성 전 반드시 사용자와 정렬.
- 🏷️ **원클릭 브랜드 시스템(Brand System) 고정**: 마음에 드는 스타일을 브랜드 표준으로 저장.
- 📐 **화면비에 맞춘 지능형 재배치**: 3:4, 2.35:1, 16:9 등 플랫폼 비율에 맞게 구도와 여백을 자동 재구성.
- 🚀 **Codex 직접 생성 ＋ Google Flow (Nano Banana) 무료 생성 듀얼 패스**.
- 🔄 **9대 오픈소스 커버 엔진 통합 라우팅**.
